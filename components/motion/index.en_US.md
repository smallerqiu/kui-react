# Motion

Provides shared motion primitives for entering, leaving, and state changes.

## Examples

[Basic Motion](./demo/basic.tsx?show=vertical)

- Click Replay to replay fade, scale, and directional slide animations.

## Usage

Add a motion class to an element. Duration and easing use the theme motion variables by default and can be overridden with `animation-duration` and `animation-timing-function`.

| Class | Description |
| --- | --- |
| `k-motion-fade-in` | Fade in |
| `k-motion-scale-in` | Scale in |
| `k-motion-scale-y-in` | Expand vertically |
| `k-motion-rotate` | Continuous rotation |
| `k-motion-slide-in-from-left` | Slide in from left |
| `k-motion-slide-in-from-right` | Slide in from right |
| `k-motion-slide-in-from-top` | Slide in from top |
| `k-motion-slide-in-from-bottom` | Slide in from bottom |

### API
| 属性     | 说明                                    | 类型           | 默认值 |
|----------|-----------------------------------------|----------------|--------|
| count    | 显示的文字                              | string，number | -      |
| color    | 徽标颜色                                | string         | -      |
| maxCount | 展示封顶的数字值，高于的部分会以+号显示 | number         | 99     |
| dot      | 不展示数字，只有一个小红点              | boolean        | false  |

### Input API
| 属性        | 说明                                       | 类型     | 默认值 |
|-------------|--------------------------------------------|----------|--------|
| value       | 输入框内容                                 | string   | -      |
| size        | 按钮尺寸,可选值 `small`、`large`，默认不选 | string   | -      |
| icon        | 输入框图标                                 | string   | -      |
| onSearch    | 搜索的回调                                 | function | -      |
| onIconClick | `icon` 的点击事件                          | function | -      |

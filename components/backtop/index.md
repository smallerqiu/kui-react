## API
| 属性    | 说明                                        | 类型     | 默认值 |
|---------|---------------------------------------------|----------|--------|
| height  | 页面滚动高度达到该值时才显示 `BackTop` 组件 | number   | 400    |
| bottom  | 组件距离底部的距离                          | number   | 40     |
| right   | 组件距离右部的距离                          | number   | 40     |
| onClick | 点击按钮时触发                              | function | -      |

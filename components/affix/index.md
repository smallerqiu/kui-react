## API
| 属性         | 说明                                      | 类型          | 默认值 |
|--------------|-------------------------------------------|---------------|--------|
| offsetTop    | 距离窗口顶部达到指定偏移量后触发          | string,number | 0      |
| offsetBottom | 距离窗口底部达到指定偏移量后触发          | string,number | -      |
| onChange     | 在固定状态发生改变时触发,返回当前固定状态 | function      | -      |
